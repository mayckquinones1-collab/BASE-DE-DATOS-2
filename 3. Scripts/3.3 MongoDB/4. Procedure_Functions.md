# 4. Procedimientos o funciones - MongoDB

**No aplica.**

MongoDB no dispone de procedimientos almacenados ni de funciones definidas por el
usuario equivalentes a los de un motor relacional. La logica de calculo del proyecto
se resuelve de dos maneras:

- **Dentro de las consultas**, mediante operadores del framework de agregacion
  (`$group`, `$sum`, `$avg`, `$cond`, `$round`). Las consultas de la seccion 5 del
  informe son el ejemplo.
- **En Cassandra**, donde si se implementaron cuatro funciones y un agregado
  definidos por el usuario en lenguaje Java. Ver `3.4 Cassandra/4. Procedure_Functions.cql`.

Confirmado con el docente del curso: el requisito de una funcion o procedimiento por
integrante se cubre en los motores que lo soportan.
